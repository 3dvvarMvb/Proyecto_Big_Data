# Hito 1: Propuesta y Definición del Problema

Este directorio contiene los documentos y entregables correspondientes al **Hito 1** del proyecto ("Definición del Problema y Propuesta de Proyecto").

---

## Contenido del Directorio

| Archivo | Formato | Descripción |
| :--- | :--- | :--- |
| **`propuesta_proyecto_fwi_bigdata.tex`** | LaTeX | Código fuente del informe inicial de propuesta de proyecto en español. |
| **`propuesta_proyecto_fwi_bigdata.pdf`** | PDF | Documento compilado con la motivación, descripción del Canadian FWI y justificación del uso de Big Data. |
| **`wildfire_fwi_bigdata_project.md`** | Markdown | Documento original estructurado con el resumen ejecutivo, alcance, datasets iniciales y tecnologías consideradas. |

---

## Cómo Compilar

Para recompilar el informe de este hito de forma aislada:
```bash
cd Propuesta
pdflatex propuesta_proyecto_fwi_bigdata.tex
```
O desde la raíz del proyecto ejecutando `./compile_all.sh`.
